🔄 FLUJO DE EJECUCIÓN MEJORADO:

ANTES (❌ PROBLEMA):
   Solicitud HTTP
        ↓
   Sin timeout → Espera indefinida
        ↓
   Conexión a BD → Puede colgar
        ↓
   60 segundos después → ERROR 504 TIMEOUT
        ✗ Usuario ve: "Ha tardado demasiado tiempo"

AHORA (✅ ARREGLADO):
   Solicitud HTTP
        ↓
   Signal alarm: 55 segundos máximo
        ↓
   Try/except alrededor de:
   ├─ Conexión a BD (Intento 1: máx 3s)
   ├─ Si falla → Intento 2 (máx 3s)
   ├─ Si falla → Usa IMG_RESPALDO (fallback)
   ├─ Query BD (máx 10s)
   ├─ Búsqueda imagen (máx 1.5s)
   ├─ Insert/update BD (máx 10s)
   └─ Respuesta JSON inmediata
        ✓ Siempre < 55 segundos

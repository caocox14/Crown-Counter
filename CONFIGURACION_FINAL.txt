✅ VERIFICACIÓN:

Si aún se cuelga:

1. Abre DevTools (F12) → Console
2. Revisa los logs en la consola del navegador
3. Abre Vercel Dashboard → Deployments → Logs
4. Copia el error exacto

Posibles errores y soluciones:

❌ "Timeout"
   → PlantNet está lento. El código ahora cortará después de 25s.

❌ "Connection refused"
   → Verifica conexión a internet. Prueba con otra imagen.

❌ "JSON decode error"
   → PlantNet retornó respuesta inválida. Usa fallback IMG_RESPALDO.
